# Todo App
This is a simple Todo App implemented in Python, where users can add, edit, show, and complete tasks using the command-line interface. The tasks are stored in a file called todos.txt. 

**Features:-**
Add Tasks: Allows the user to add new tasks to the list.

Show Tasks: Displays all the tasks in the list with their index.

Edit Tasks: Enables the user to edit any existing task by selecting it by index.

Complete Tasks: Allows the user to remove a task from the list once it's completed.

Persistent Storage: All tasks are saved in a file (todos.txt), and remain between app runs.

**Additional Notes:-**
Error Handling: The app gracefully handles invalid commands (e.g., entering a non-numeric value for task editing or completion).
